## 🏯 这是个什么靶场?

一句话概括:**以中国修真文化为载体的 PHP Web 安全攻防教学平台**。

在 这里,你不是在"做题",你是一名初入宗门的修真弟子:

- **炼气期**练的是信息泄露、弱口令这些"吐纳之术";
- **筑基期**开始修炼 XSS、CSRF、SQL 注入基础;
- 金丹、元婴一路进阶 XXE、SSRF、反序列化、越权;
- 到了**大乘期**,面对的就是综合渗透和真实 CVE 复现;
- **100 关全通**,触发"飞升大典"——九重天雷渡劫动画,颁发你的专属通关文牒。

**三大宗门**对应三条技术线:青云宗(正道)主修 XSS/CSRF/认证,万魔宗(魔道)专研反序列化/RCE/SSRF,轮回宗(玄门)深耕 SQL 注入/XXE/密码学。

**八阶境界 · 100 关卡**,覆盖 OWASP Top 10 + 业务逻辑漏洞 + 现代 Web 漏洞,难度从 ⭐ 到 ⭐⭐⭐⭐⭐ 循序渐进。

## 📖 不会做?每关都有"师父"带着走

很多靶场的通病:给你个页面,给了密码,然后就没有然后了。

修真靶场把每个关卡拆成**三阶段学习闭环**:

1. **习道 📖**——先讲漏洞原理、修真剧情背景、攻击思路。知其然,更知其所以然。
2. **试炼 ⚔️**——进入真实靶场环境动手实操。卡住了?**三级提示系统**(弱提示 → 中提示 → 完整提示)循序渐进地点拨你,不是直接把答案拍你脸上。
3. **悟道 🌟**——通关不是终点。这里有完整 Writeup、**漏洞代码 vs 安全代码左右对比视图**、根因分析与防御方案,让你从攻击者视角切换回守护者视角。

这一套走下来,一关就是一个完整的学习单元,特别适合自学和教学使用。

## 🚀 一键启动,30 秒开练

Docker 一条命令跑起来,不需要折腾环境:

```bash

cd xiuxian-range
docker-compose up -d
```

## 🛠️ 技术上的一些设计

写给感兴趣的朋友:

- **原生 PHP 8.2,无框架**:每一行代码都可审计、可教学,不会让学习者陷在框架魔法里
- **平台自身遵循安全最佳实践**:PDO 参数化查询、Argon2id 密码哈希、全局 CSRF Token、Session 定期轮换——教人攻击的地方,自己先守住
- **Flag 随机化**:所有关卡 Flag 与彩蛋口令在数据库初始化时随机生成,杜绝"提前从源码里翻答案"
- **MySQL 8 + Redis 7 + Bootstrap 5 自研修真主题**,提供 Docker 一键部署
- **关卡可持续扩展**:按目录约定丢进新关卡 + 添加种子数据即可,附审核脚本验证可通性
